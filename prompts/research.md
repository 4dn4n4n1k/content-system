# Research stage — instructions for Claude

Input: `projects/<slug>/source.json` (reference video transcript + metadata).
Output: `projects/<slug>/research.md`.

1. Read the transcript and extract the video's **outline**: hook, sections, key claims, examples, and the retention devices it uses (open loops, stakes, payoffs).
2. **Web-search every factual claim** worth repeating: verify it, find the primary source, and check whether it's outdated. AI/cybersecurity moves fast — a 6-month-old stat is often stale.
3. Find **2–3 original angles** the reference video missed: newer incidents, better examples, a contrarian take, or a practical demo idea. This is what makes our video better, not a copy.
4. Write `research.md` with:
   - `## Outline of reference video` (structure only, never phrases to reuse)
   - `## Verified facts` — each with source URL and date
   - `## Corrections / outdated claims` — what the reference got wrong or stale
   - `## Original angles` — what we add
   - `## Suggested title + thumbnail concepts` — 3 options, curiosity-driven, no clickbait lies

Rules: never copy sentences or distinctive phrasing from the transcript. Facts and
structure are not copyrightable; expression is.
